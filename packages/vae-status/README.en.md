# dsh-vae-status

[中文](README.md) | English

Canary bundle: registers `vae_status` so you can prove install and Web visibility.

```sh
pnpm dsh plugin --profile web add /home/dsh-vae-plugin/packages/vae-status
pnpm dsh plugin --profile web add github:veaaae/dsh-vae-plugin#path:packages/vae-status
```

See the [root README](../../README.en.md) for the workspace layout and how to add another plugin.
